## Notes for the POE
- These wireframes are based on the current HTML and CSS structure in the repository.
- The mobile versions show the stacked layout used at the mobile breakpoint.
- The Shop page currently uses designed text placeholders rather than product photographs. Product images were not added in this update.
- If the lecturer requires graphical wireframe images rather than low-fidelity text wireframes, recreate these layouts in the required design tool and insert the exported diagrams into the POE document.
